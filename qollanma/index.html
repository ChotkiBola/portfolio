Claude uchun Instagram yordamchi: bitta fayl, 13 ta skill

Profilingizni tahlil qiladi, reels ssenariysini yozadi, caption tuzadi, haftalik kontent plan beradi. Bitta faylni Claude'ga tashlaysiz, xolos. Bepul.

3 qadam, tamom

Hech narsa o'rnatish shart emas. Telefonda ham ishlaydi.

  1. Faylni yuklab oling.
    Instagram yordamchi faylini yuklab olish
  2. Claude'ga tashlang. claude.ai yoki Claude ilovasida yangi chat oching, + yoki 📎 tugmasini bosib, shu faylni biriktiring.
  3. Nima kerakligini yozing. Masalan: 
    Profilimni tahlil qil va bio'ni qayta yoz: instagram.com/username
    Shu g'oyadan 30 soniyalik reels ssenariysi yoz: ...
    Menga bir haftalik kontent plan tuzib ber. Sohasim: ...

Har yangi chatda faylni qayta tashlaysiz. Ssenariylar o'zingizga o'xshab chiqishi uchun 2–3 ta eski reelsingiz matnini ham qo'shib yuboring.

Nimalar qila oladi

Buyruqni yozishingiz shart emas, oddiy so'z bilan so'rang. Claude o'zi mosini tanlaydi.

/ig-profile

Profilingizni 100 balldan baholaydi va bio'ni qayta yozadi.

/ig-reel

G'oyadan reels: 3 ta hook, ssenariy, ekrandagi matn.

/ig-caption

Caption yozadi, "... ko'proq"gacha ko'rinadigan qismini tekshiradi.

/ig-plan

Haftalik plan: nima, qaysi formatda, qachon joylash.

/ig-viral

Sohangizda hozir ishlayotgan reelslarni topib, sababini aytadi.

/ig-audit

Joylagan postlaringizni tahlil qiladi: nima ishladi, nima yo'q.

/ig-story

Kunlik stories ketma-ketligi va qaysi stiker qayerga.

/ig-carousel

Karusel: muqova, slaydlar matni va rasmlari.

/ig-reply

Postingiz ostidagi izohlarga javoblar tayyorlaydi.

/ig-dm

DM matnlari: kalit so'z javobi, hamkorlik taklifi.

/ig-comment

Boshqalarning postiga bot bo'lib ko'rinmaydigan izohlar.

/ig-repurpose

Bitta uzun videodan bir haftalik reels va karusellar.

/ig-human

Matndan "AI hidi"ni tozalaydi, tabiiy qiladi.

Har safar tashlamaslik uchun

Faylni har chatda biriktirish erinarli bo'lsa, skillarni Claude'ga bir marta o'rnatib qo'ying. Kompyuterda qilish qulayroq.

O'rnatish yo'riqnomasini ochish

1-yo'l: claude.ai yoki Claude ilovasi

Ko'pchilik uchun shu. Bepul tarifda ham ishlaydi.

  1. Skillarni yuklab oling:
    Hammasini yuklab olish (13 ta skill)
    Faylni oching (unzip). Ichida 13 ta alohida .zip fayl bor, ularni ochmang, o'zini yuklaysiz.
    Yoki bittalab yuklab oling
    ig-profileig-reelig-caption ig-planig-viralig-audit ig-storyig-carouselig-reply ig-dmig-commentig-repurpose ig-human
  2. claude.ai'da Settings → Capabilities ga kiring va Code execution (yoki "Create and edit files") ni yoqing. Skillar shusiz ishlamaydi.
  3. Customize → Skills ga o'ting, + tugmasini bosib, skill yuklash variantini tanlang.
  4. Bitta .zip faylni yuklang. Har bir skill uchun shuni takrorlang. Boshlash uchun eng kerakli uchtasi yetadi: ig-profile, ig-reel, ig-plan.
  5. Yangi chat oching va yozing: /ig-profile va Instagram profilingiz linki.

Skill yuklash kompyuterda (brauzer yoki desktop ilova) qulayroq. Yuklab bo'lgach, telefondagi Claude ilovasida ham ishlataverasiz.

2-yo'l: Claude Code

Kompyuterda Claude Code ishlatsangiz.

  1. Plagin sifatida o'rnating: 
    /plugin marketplace add Jakeschincariol/instagram-agent-skill
  /plugin install instagram-agent
  2. Yoki terminalda qo'lda: 
    git clone https://github.com/Jakeschincariol/instagram-agent-skill.git
  cp -r instagram-agent-skill/skills/ig-* ~/.claude/skills/
  3. Claude Code'da /ig-reel deb yozib tekshiring.
